# Smart Employment Portal - Bislig City Pilot (GitHub Pages version)

Runs entirely in the browser: no server, PHP or database needed. Data is saved in each visitor's own browser (localStorage), so it is not shared between users or devices.

Open `index.html`, or publish with GitHub Pages (Settings > Pages > Deploy from a branch > main > / (root)).
